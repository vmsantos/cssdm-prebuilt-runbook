- awp_dust_fun

## Source

The BSPs were pulled from the `HydroJ1/fast-dl` mirror repo and then copied to the live server.

## Note

FastDL hosting still needs a dedicated HTTP endpoint. The server currently has the map files locally, so joins work, but FastDL is the next step for faster client downloads.
